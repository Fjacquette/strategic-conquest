# Saved games: Strategic Conquest 3.01

All from one single-player game at skill level 1, played in the emulator. The first city
produces Armies. Saves are written at the end of a round, after the computer's move, so
each file records the start of the day shown.

| File | Day | State |
|---|---|---|
| `s01-day4.sav` | 5 | First Army built at the starting city (column 38, row 28) on day 4; its move was skipped. |
| `s02-day5-army-east.sav` | 6 | Same game; on day 5 the Army moved one square east to column 39, row 28. |
| `s03-day57-autoplay.sav` | 57 | Same game after Auto Play was switched on at day 6. |
| `s04-day58-autoplay.sav` | 58 | One round after `s03`. |
| `s05-hotseat-day2.sav` | 3 | A separate "2 Player Single Mac Game" (game mode 1, skill 4), each side's first Army built and its move skipped. |
